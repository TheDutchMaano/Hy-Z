# Hy-Z — Basic Site

This folder contains a simple static landing site for the Hy-Z survival zombie game.

To preview locally run a simple HTTP server. Example (Python 3):

```bash
python -m http.server 8000

# then open http://localhost:8000 in your browser
```

Files added:
- `index.html` — main landing page
- `about.html` — about and goals
- `styles.css` — site styles
- `script.js` — minimal interaction
- `assets/favicon.svg` — small favicon
